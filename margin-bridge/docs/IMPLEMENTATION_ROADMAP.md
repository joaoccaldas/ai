# Implementation roadmap

## Phase 0: Definition and controls

Agree metric definitions, FX policy, product hierarchy, materiality, version naming and ownership.

## Phase 1: Controlled pilot

Load one market and one BU, reconcile to SAP/SAC and run the model in parallel for one cycle. Keep all writes out of production.

## Phase 2: Nordic commercial model

Add all markets and BUs, formal FC snapshots, comments, approvals, scenario storage and native XLSX templates.

## Phase 3: SAC integration

Generate validated SAC load files or connect through a governed API. Add pre-load validation, rejection logs and post-load reconciliation.

## Phase 4: Decision intelligence

Add customer/channel, promotions, lifecycle, inventory constraints, full nonlinear simulations and forecast-accuracy learning.
