# Anxious or Blue immersive concept

Responsive redesign concept for [anxiousorblue.com](https://anxiousorblue.com/), built as a self-contained GitHub Pages experience.

## Route

`/ai/studio/anxiousorblue/`

## Design principles

- Preserve the original clinic content, contact details, calls to action and imagery.
- Communicate calm, peace and nuanced optimism without making therapy feel trivial.
- Use gentle ambient motion, progressive disclosure and clear content hierarchy.
- Keep booking actions connected to the original Anxious or Blue website.
- Support desktop, tablet and mobile layouts.
- Respect `prefers-reduced-motion` and keyboard navigation.

## Responsive behavior

- **Desktop:** spatial hero, subtle pointer depth, full navigation and larger editorial layouts.
- **Tablet:** stacked feature sections and simplified spatial effects.
- **Mobile:** content-first hero, touch menu, horizontal issue cards and a consultation button that appears after the visitor begins scrolling.

## Source assets

The concept references the original Anxious or Blue logo, clinic and portrait images from the live website so the visual identity and factual content remain aligned with the source.
