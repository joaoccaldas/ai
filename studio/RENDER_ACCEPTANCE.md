# Studio render acceptance

The Studio landing page is accepted only when all of the following are true:

- The desktop lobby screenshot resembles the approved dark luxury gallery art direction.
- The page uses photorealistic room imagery rather than visible primitive geometry as the main architecture.
- At least one room transition is visible in a browser-rendered screenshot or recording.
- Desktop and mobile screenshots are attached as CI evidence.
- The deployed GitHub Pages URL serves the same version as `main`.
- No uncaught browser errors occur during the automated render.

The `Studio Visual Render` workflow captures this evidence for every Studio pull request.
