# Atoll Ascent Maldives

A Caldas Studio concept for a small-field luxury endurance journey in the Maldives.

Live route: https://joaoccaldas.github.io/ai/studio/atoll-ascent/

## Product concept

- 24 founding guests
- 7 nights
- 4 race stages
- 3 deliberate recovery days
- Yacht-led race logistics and premium island hospitality
- English + Brazilian Portuguese
- USD / EUR / BRL display
- Optional 3-night surf extension:
  - Lohis / Adaaran Select Hudhuran Fushi
  - Private surf liveaboard ("Swell Chaser")

## Why Addu

Most Maldivian resort islands are too small for a meaningful road-cycling stage. Addu is unusual because the western inhabited islands are linked by road from Gan through Feydhoo, Maradhoo / Maradhoo-Feydhoo to Hithadhoo.

The website deliberately labels the itinerary illustrative. A real event would require course measurement, traffic management, marine safety, medical planning, permissions for protected areas, insurer sign-off and local operator contracts.

## 3D

The production page uses a lightweight live Three.js interpretation of the atoll so GitHub Pages has no heavy binary dependency.

The Blender source generator lives at studio/atoll-ascent/blender/build_atoll_ascent.py. It creates:
- lagoon and atoll rim
- connected island chain
- race route
- yacht
- course markers
- surfboard object

The Blender bake can replace the procedural hero after art-direction sign-off without changing the content layer.
