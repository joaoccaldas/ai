# Atoll Ascent Maldives

A Caldas Studio concept for a seven-night, four-stage luxury triathlon and recovery journey in Addu Atoll, Maldives.

Personal experimental project by a self-taught builder. AI is used extensively across research, prototyping, visual design, coding, documentation and testing as part of the learning process. Claims affecting real-world operations must be independently validated with local specialists before launch.

## Why Addu

Most Maldivian resort islands are too small for a credible road-bike stage. Addu is unusual: the western inhabited islands are connected from Gan toward Hithadhoo. Visit Maldives describes a 16 km link road, while Addu tourism planning describes an approximately 30 km out-and-back corridor suitable for cycling and triathlon. That makes a 60 km finale possible as two controlled laps, subject to permits, closures and safety planning.

## Experience architecture

- 24 athletes maximum
- 7 nights / 8 days
- Day 1 arrival and bike build
- Days 2–5 four escalating race stages
- Days 6–8 three recovery days, with departure after the final recovery morning
- Private premium liveaboard or yacht as race clubhouse
- Addu resort recovery stay with overwater or pool-villa inventory
- Concierge bike handling, timing, boats, mechanics, physio and recovery programming

## Website

The site is intentionally static and compatible with GitHub Pages. It uses the repository's vendored Three.js build and no frontend framework.

- index.html: semantic page
- styles.css: responsive visual system
- app.js: EN/PT content, EUR/USD/BRL display, itinerary, newsletter handoff and Three.js scene
- blender/atoll_ascent_scene.py: reproducible Blender source for a matching editable 3D asset

The newsletter form fails safely. GitHub Pages cannot protect secrets, so until a secure endpoint is configured the form opens a pre-addressed email instead of pretending to store data.

USD is the base commercial model. EUR and BRL are indicative display conversions using the open-source Frankfurter API when available.

## Validation before sale

Event and tourism licensing, road and police approvals, marine risk assessment, beach access, environmental restrictions, medical and evacuation coverage, insurance, vessel/resort contracts, bike-freight limits, local taxes, cancellation rules and athlete qualification all require formal validation.
