# Atoll Ascent Maldives — public concept build

Live concept: https://joaoccaldas.github.io/ai/studio/atoll-ascent/

This is a non-commercial concept prototype for a 24-person luxury endurance expedition in Addu Atoll, Maldives.

## What is real vs TBC

- Real: Addu geography and tourism/activity context.
- Real: Hudhuran Fushi / Lohis surf operating constraints published by the resort.
- Planning only: event dates, course distances, accommodation partner, event permits, medical/marine plans, package prices and surf-charter inventory.
- No deposits are accepted.
- Interest button opens a local email draft and stores no personal data.
