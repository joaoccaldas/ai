Belong

A landscape-led website that turns a sense of place into a living, changing atmosphere.

Focus
Visual design · shader environments · web development
Stage
Independent website concept
Tools
JavaScript · WebGL · GLSL · CSS
Visit the experience ↗

01 / The question

How can a website communicate the feeling of a place before a visitor reads its story?

02 / The approach

Belong uses an atmospheric browser landscape, day and night lighting and a scroll-led narrative to connect environment and content. The scene is part of the visual identity, rather than a separate decoration.

  • A real-time environment changes the mood of the page.
  • Typography and scrolling place the story within the landscape.
  • The project includes its own browser smoke checks.

03 / Where it stands

An implemented creative website concept. It is presented as an independent design study; client adoption or business impact has not been established.

04 / What comes next

Strengthen the static fallback and evaluate readability and performance on lower-powered devices.
