THE METHOD

Truth underneath.
Wonder on top.

01

Own the input

Your imported file is processed in memory, not sent to a backend. Strava API access is deliberately not used in this version.

02

Keep the measurement

GPS-derived distance, source timestamps, elevation and optional HR remain distinguishable from decorative terrain.

03

Reconstruct carefully

Procedural nature, lighting and perspective are storytelling layers. This is a 3D route sculpture, not a surveyed digital twin.
