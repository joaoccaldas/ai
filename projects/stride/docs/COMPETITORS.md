# Competitor/alternative landscape / source checked 2026-10-19

## Evidence

- Strava Flyover supports subscriber 3D flyovers of routes, activities, segments, live statistics and sharing: https://support.strava.com/en-us/articles/15401641-flyover
- Relive Plus includes 3D interactive routes, old activities, photos/video/musical customization, HD exports. Public reference price USD 38.99/year, USD 6.99/month (regional prices change): https://www.relive.com/plus
- VeloViewer Explorer has Explorer Tiles, connected tiles and max square/cluster challenges: https://blog.veloviewer.com/veloviewer-explorer-overview/
- ROUVY: https://rouvy.com/ : real-world-route indoor cycling simulations; verify current details and pricing before sales comparisons.
- Kinomap: https://www.kinomap.com/ : geo-linked training videos/connected equipment; verify current details and pricing before sales comparisons.

## Why the category needs a new job

A generic 3D flyover is table stakes, not a moat. Current products already explain route geography or produce shareable animations. STRIDE must create a personal, interactive, explorable route memory with data provenance, moment navigation, consented progress comparisons, and adaptive scene quality, not repackage a competitor's core feature.

## Fair comparison test

For the same permissioned activity file, score time to first insight, correctness of identified best/split/climb moment, route geometry fidelity, clarity of measured vs illustrative attributes, mobile time-to-interactive, rendering stability, share privacy, subjective wow/memorability, retention, and willingness to pay. Do not benchmark Strava via its API; use permitted manual public product evaluation.

## Moat candidates (hypotheses, not claims)

1. Reusable, scene-independent "activity moment" contract across sports and media outputs.
2. Versioned 3D factory with provenance, budgeted assets, visual QA, reproducible benchmarks.
3. Personal memory environments and own-file data portability, lawful and vendor-independent.
4. Strong understanding of training semantics via opt-in permitted Performance OS adapter, never shadowing its data authority.
5. B2B licensed storytelling pipeline for races/brands/coaches, independent of Strava API dataset restrictions.

## Threats

Incumbents can add scene templates; video rendering is relatively commoditized; accurate satellite/3D terrain imagery is licensed; crowdsourced geographic datasets have terms; athletes may not revisit old sessions often; rendering on budget phones may disappoint; name STRIDE likely needs legal/trademark clearance.
