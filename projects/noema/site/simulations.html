Stress-test descriptive patterns against explicit null models. This first lab uses Pulotu feature profiles and a permutation null that preserves marginal prevalence.

Naive co-occurrence null

Is a pattern surprising?

Choose two accepted mapped components. NOEMA shuffles one component across cultural profiles while preserving how common each feature is, then compares simulated overlaps with the observed overlap.

This is a deliberately weak null. It does not correct for language-family ancestry, geographic proximity, known contact, ecology, shared coders or missingness. A strong result here means “worth testing with better models,” not “historically connected.”
