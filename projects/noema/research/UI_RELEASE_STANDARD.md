# NOEMA UI Release Standard

The public interface is a research instrument, not a marketing microsite. Every major surface should expose enough context to answer four questions without leaving the page:

1. What am I looking at?
2. Where did it come from?
3. How uncertain or incomplete is it?
4. What can I compare or test next?

## Required command-center modules

- global search across reference entities, Pulotu and DRH
- source/data freshness
- scheduled-research pulse
- research-health / semantic coverage
- review queues and unapproved-state warnings
- pattern candidates with sample size and unresolved confounders
- hypothesis revisions and recent no-change findings
- media candidates / approved-media state
- deep-time atlas entry point
- clear links into source-specific forensic workbenches

## Visual principles

- provenance and uncertainty must be visible, not hidden in tooltips
- visually distinct source families and evidence/review states
- charts should encode real analytical quantities, not decorative percentages
- absent, unknown, contested and uncoded must never share one visual state
- responsive, keyboard-usable, reduced-motion compatible
- no image without provenance and rights status
- no pattern edge without cohort/sample metadata and candidate status
