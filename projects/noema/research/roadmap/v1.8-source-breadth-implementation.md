# NOEMA v1.8 — Source Breadth & Source-Dependence Implementation Plan

## Objective

Reduce blind spots and duplicated-evidence risk before stronger causal/phylogenetic modeling.

## Adapters / linkers

### 1. Seshat Global History Databank
- polity/time variables
- religion/ritual variables
- social-complexity context
- variable-level citations and coding notes
- versioned snapshot required

### 2. ARIADNE
- archaeological datasets, sites and objects
- place/time/provider metadata
- rights and landing-page provenance
- discovery/context only unless underlying evidence is reviewed

### 3. OpenAlex
- work identity
- DOI reconciliation
- citation graph
- concepts/topics only as discovery metadata
- citation overlap may indicate dependence but never proves it

### 4. Pleiades
- ancient place authority IDs
- coordinates and historical names
- period-aware place reconciliation
- location linking only, not religious interpretation

### 5. PMC / Europe PMC
- abstract/full-text enrichment when licensing permits
- PMID/PMCID/DOI reconciliation with PubMed
- structured text used only after article-level review

## Source-dependence graph

NOEMA must distinguish independent evidence from repeated publication of the same underlying observation/dataset.

Minimum edge types:

- SAME_DATASET
- REUSES_DATASET
- DERIVED_FROM
- CITES_FOR_CLAIM
- SAME_FIELD_SITE
- SAME_EXCAVATION
- SAME_COHORT
- SAME_ARCHIVE
- SAME_REVIEW_CORPUS
- POSSIBLE_DEPENDENCE

Every edge records provenance, confidence, reviewer/state and source locator.

## Validation

Each adapter must have:

- deterministic ID normalization
- duplicate handling
- explicit missingness
- license/rights field
- version/snapshot field
- source-specific epistemic note
- tests proving discovery metadata cannot become approved evidence
- failure/freshness reporting in Research Health

## PubMed cross-domain pilot

The biomedical layer should be linked to the source-dependence graph immediately because reviews, case reports, reused cohorts and secondary analyses are especially easy to double-count.

Pilot domains:

- autism/schizotypy ↔ religiosity/spirituality
- epilepsy/seizure ↔ religious experience
- trance/possession ↔ dissociation
- psychedelics ↔ mystical-type experience
- sleep/dreaming ↔ supernatural-agent perception

Historical witchcraft/persecution analysis remains downstream and must use non-diagnostic phenomenology plus independent historical/legal/social data.

## Exit criteria for v1.8

- at least 3 of 5 source families have working candidate-only adapters/linkers
- source snapshots are versioned
- source-dependence graph exists and is visible in Research Health
- PubMed candidates can be reconciled to DOI/PMCID/OpenAlex work identities without evidence promotion
- CI contains adapter-specific guardrails
- no new source can bypass human claim review
