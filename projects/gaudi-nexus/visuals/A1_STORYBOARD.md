# A1 storyboard v0

This is intentionally a skeleton before design.

## Reading order
1. **One-sentence thesis** — the urban conflict and our architectural answer.
2. **Hero** — one image proving the square belongs to daily Barcelona while Sagrada retains visual primacy.
3. **Problem model** — locals, tourists, view field, sun, noise, movement.
4. **Form-finding** — inputs → structural/environmental rules → geometry.
5. **Plan** — program and flows.
6. **Section** — structure, passive climate, viewpoint and human scale.
7. **Gaudí logic** — 2–4 precise translations, not a decorative checklist.
8. **AI workflow proof** — where AI generated options, where simulation rejected them, where humans decided.
9. **Micro-detail** — one buildable market/stall/joint/material moment.
10. **Outcome metrics** — only metrics we can honestly defend.

Rule: if a visual does not answer a likely jury question, it does not get space.
