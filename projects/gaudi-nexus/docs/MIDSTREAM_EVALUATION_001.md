# Midstream Evaluation 001 — 2026-10-04

## Executive verdict
The project has crossed from idea exploration into credible design development.

What is genuinely strong:
- evidence discipline;
- competition requirements encoded as constraints;
- real site geometry replacing placeholder geometry;
- explicit concept divergence and kill decisions;
- evidence-driven iteration of the Living Threshold;
- market/service operations;
- code-screen thinking;
- repeatable 5 m structural bay;
- joint/maintenance logic;
- optional A4 stall concept;
- coherent AI/process provenance.

What is still weak:
- authoritative municipal 3D/topography is not in the master model;
- there is no single authoritative Blender model;
- structural analysis remains proxy-level;
- annual daylight/wind/thermal proof remains proxy-level;
- material and lighting realism are below competition standard;
- the primary human experience has not yet been proven in a high-quality render;
- A1 board communication is still the only explicit red competition requirement;
- the project is still staged inside a public `ai` repository branch.

## What was worth doing

### 1. Competition OS
High value.
It prevented a beautiful but non-compliant project and made requirements, evidence, risks, decisions and gates explicit.

### 2. Site truth before form
High value.
The generic Cerdà block was replaced with real plaza/basilica/context geometry, so concept placement could be falsified spatially.

### 3. Five divergent concepts
High value.
The project avoided premature convergence and produced reusable insights:
- Cerdà Mutation → geometric method;
- Market Organism → service metabolism;
- Living Threshold → civic topology.

### 4. Kill tests
Very high value.
Living Threshold V0.1 and V0.2 were changed when view, service-distance and winter-shadow proxies failed. This is evidence that the workflow can reject its own preferred geometry.

### 5. Market/operations work
Very high value.
The 20-stall layout, service path, storage, waste, WCs, independent evening operation and accessible counter make the project architecturally credible rather than diagrammatic.

### 6. Code screening
High value.
It forced larger stair/circulation reservations and exposed the civic upper floor as the controlling occupancy case.

### 7. 5 m bay + joints
High value.
The project gained a repeatable construction DNA instead of relying on one-off sculptural forms.

### 8. Performance proxies
Medium-high value.
Solar fins, rainwater, acoustics and thrust studies are useful for direction-setting, but must not be mistaken for final simulation.

### 9. Interactive Three.js / GLB
Medium value now, high portfolio value later.
Useful for spatial falsification and consistency. Not the competition's core deliverable.

### 10. Extensive diagrams
Mixed value.
Early diagrams were essential for thinking. Additional diagrams now have sharply diminishing returns unless they directly replace a red/yellow requirement.

## What we over-invested in
- repeated proxy diagrams after the architectural direction was already clear;
- manual diagram rendering that does not yet feed an authoritative Blender model;
- several generations of scoring that risk false precision;
- interactive/web output before final visual quality exists.

These were not wasted, but the marginal return is now low.

## Why the chosen route remains defensible
The competition rewards architecture, urban context, Gaudí logic, AI/spatial coherence, sustainability and communication.
A prompt-to-image route would optimize the final 10 points before securing the other 90.

The selected process instead optimized:
1. correctness;
2. spatial coherence;
3. operational credibility;
4. falsifiability;
5. then representation.

That ordering remains correct.

## Current primary scheme
**Living Threshold A+**

Hierarchy:
- A = architecture / civic topology;
- C = geometric method;
- E = market/service subsystem.

This hierarchy avoids concept soup.
