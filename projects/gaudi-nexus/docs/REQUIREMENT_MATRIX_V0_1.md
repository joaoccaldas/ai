# Competition Requirement Matrix V0.1

## Purpose
No competition requirement is allowed to disappear inside the design narrative.

The project tracks each requirement as:
- **GREEN** — concept requirement demonstrably satisfied;
- **YELLOW** — credible direction exists, but proof is incomplete;
- **RED** — requirement not yet competition-ready;
- **CONTROLLED** — submission/process requirement encoded but only closable at final QA.
