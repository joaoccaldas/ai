# Primary 3D V0.1

## Status
First interactive 3D design-development model of **Living Threshold A+ V0.5**.

This is the first model intended to be inspected spatially rather than only through plans/sections.

## What is authoritative
- two-bar topology;
- local placement;
- ~45 m × 10 m bar dimensions;
- 5 m longitudinal rhythm;
- ~4.8 m enclosed eave datum;
- ~1.4 m catenary-informed roof rise;
- hard bar versus civic bar distinction;
- 20-stall hard-bar market logic;
- open civic middle.

## What is not authoritative yet
- detailed structure sizing;
- exact roof build-up;
- façade system;
- exact tree locations;
- municipal context heights;
- detailed Sagrada geometry;
- final daylight/shadow;
- final materials;
- competition-grade rendering.

## Visual rule
A 3D view only passes if it preserves the same plan dimensions and spatial relationships as the project contract.

No AI-generated perspective may override this model.
