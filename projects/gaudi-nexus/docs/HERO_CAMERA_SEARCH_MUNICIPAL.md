# Hero Camera Search — Municipal Context

## Conclusion

The previous HeroCam is retained as a secondary market-atmosphere view but rejected as the final jury hero.

A ray-cast grid across the plaza found 106 human-height positions with an unobstructed path to the cathedral proxy target. These positions were then rendered against the aligned **municipal** context.

## Selected geometry candidate

**A_HERO_MUNICIPAL_F3**

- eye height: 1.56 m
- lens: 32 mm
- position: (-15.0, 42.0, 1.56)
- target: (96.1, 100.4, 30.0)
- source scene: Rev17 aligned municipal comparison

## Why F3

Compared with the other tested views, F3 best balances:
- legible Sagrada relationship;
- visible Living Threshold edge/ceramic system;
- human/plaza foreground;
- human-eye scale;
- no need to modify architecture purely for the image.

This is a **geometry selection**, not final visual approval.

## Next
