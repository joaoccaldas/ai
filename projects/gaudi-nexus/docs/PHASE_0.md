# Phase 0 — Competition OS + Site Truth

## Why this comes first
The main failure mode is producing seductive AI architecture before the real problem is modeled. Phase 0 prevents that.

## Gate 0A — Brief lock
- [ ] Official brief archived locally with checksum.
- [ ] Every mandatory requirement represented in `config/requirements.json`.
- [ ] Every scoring criterion represented in `config/rubric.json`.
- [ ] Ambiguities logged, never silently guessed.
- [ ] Eligibility, anonymity, IP and AI provenance constraints reviewed.

## Gate 0B — Site truth
- [ ] Fixed coordinate reference and local origin.
- [ ] Cerdà block and street dimensions checked against at least two sources where possible.
- [ ] Sagrada context massing separated from proposal geometry.
- [ ] View corridors recorded as geometry, not screenshots.
- [ ] Solar path and true north verified.
- [ ] Existing trees / major public-space elements catalogued.
- [ ] Tourist and resident flows stored as hypotheses with evidence/confidence, not facts unless sourced.

## Gate 0C — Reproducibility
- [ ] One command validates project state.
- [ ] Blender scripts are deterministic for identical inputs.
- [ ] Render cameras and color-management settings are versioned.
- [ ] Generated outputs are traceable to source data and parameters.

## No-go conditions
Do not advance to polished concept design if:
- the site coordinate system is uncertain;
- required program cannot be reconciled;
- the primary Sagrada view logic is not encoded;
- a concept's structural story cannot be expressed without hand-waving;
- AI-generated imagery is becoming the source of spatial truth.
