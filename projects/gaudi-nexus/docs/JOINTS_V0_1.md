# Construction Interfaces V0.1

## J01 — Pier → Edge Beam → Shell
Design intent:
- robust mineral/precast vertical support;
- explicit springing block;
- movement/bearing layer between frame and shell;
- compression shell remains geometrically legible;
- waterproofing remains continuous;
- rainwater collection is visible and serviceable;
- ceramic sun-control is independently bolted and replaceable.

Failure modes to test next:
- local springing stress;
- thermal movement;
- waterproofing continuity;
- gutter overflow;
- downpipe maintenance;
- bracket corrosion;
- fin wind loading;
- shell edge cracking.

## J02 — Stall → Floor → Service
Design intent:
- no permanent market fit-out cast into civic ground;
- service plinth handles water / power / data;
- stall uses quick connection;
- wash-down drains are accessible;
- accessible counter is integral;
- fold-down bench supports evening civic mode.

Failure modes to test next:
- hygiene zoning;
- drainage slope;
- spill containment;
- refrigeration heat rejection;
- plug durability;
- accessible reach;
- cleaning access;
- theft/security in closed mode.

## Rule
A detail only remains if it improves at least one of:
- force path;
- water management;
- solar control;
- acoustics;
- accessibility;
- operations;
- maintenance;
- material longevity;
- human experience.
