# Hardware accuracy, history and simplifications

CPU Studio is a **historically anchored lesson game**, not an emulator or physical servicing manual. Each mission presents a plausible *configuration of its period*. Product names and dates are educational references; game hardware artwork is original generic CSS/SVG art, not licensed product design.

| Era | Reproduced concept | Evidence | Simplification / boundary |
|---|---|---|---|
| **1975 kit** | Altair-inspired hobby computer; Intel 8080-class S-100 CPU board, 256-byte memory, front-panel switches and LEDs; later S-100 RAM upgrade | Computer History Museum, [1975 timeline](https://www.computerhistory.org/timeline/1975/), [Homebrew Computer Club](https://www.computerhistory.org/revolution/personal-computers/17/312) | Built-in screen and floppy are intentionally **not shown** in 1975. Power supply and bus are provided in the simulated kit. S-100 kit assembly procedures are not physically simulated. |
| **1981 early personal PC** | 8088 CPU, 64 KB RAM configuration, 5¼-inch boot floppy; optional CGA expansion | [IBM: History of the PC](https://www.ibm.com/history/personal-computer), especially 16 KB original baseline and later expansion; original CPU Intel 8088 | Memory 64 KB is a valid illustrative early configuration, not the specification of every 1981 IBM PC. A 16-bit-core / 8-bit-bus CPU and boot disk are simplified into three slots. |
| **1995 multimedia** | 133 MHz Pentium-class CPU, Socket 7 era motherboard, 72-pin EDO SIMM, IDE storage, PCI VGA, optional ISA sound | [Intel 1995 processor introductions](https://www.intel.com/pressroom/kits/quickrefyr.htm), [CHM 1993 Pentium introduction](https://www.computerhistory.org/timeline/1993/) | Component pairing is a representative PC configuration, not a brand-specific factory model. Sound, video, RAM timings and mechanical setup are abstracted. |
| **2005 LAN / graphics** | Socket 939-class Athlon 64 + first-generation DDR and PCI Express GPU + SATA hard drive + network adapter | Historical component-generation constraints: [AMD platform overview](https://www.amd.com/en) and period 2004–2005 Socket 939/PCIe references; [Roblox retention docs](https://create.roblox.com/docs/production/analytics/retention) apply only to gameplay, not hardware | **DDR2 deliberately fails** on the specified DDR Socket 939 platform. This is not a universal assertion about all 2005 PCs, many of which supported DDR2 on other sockets. |
| **2026 modern creator** | AM5 Ryzen 5 7600 class CPU, DDR5, NVMe, heatsink, ATX power, optional discrete GPU on the first creator level | [AMD Ryzen 5 7600 specifications](https://www.amd.com/en/products/processors/desktops/ryzen/7000-series/amd-ryzen-5-7600.html) | Ryzen 5 7600 was launched in **2023**, not 2026; it is a valid CPU *used in a 2026 build*. It includes integrated graphics. A discrete GPU is needed for the final performance goal, but not intrinsically for all display output. |

## Physics and compatibility scope

- **Actually checked in code:** specific stage-appropriate processor, memory family, media/storage interface, graphics/network/audio/cooling/power required by the authored blueprint, power-off-before-repair, optional integrated-graphics path for the 2026 stage.
- **Not yet checked:** actual wattage headroom under GPU load, socket pin maps, bus frequency negotiation, connector polarity/cable fit, BIOS firmware support, power-on self-test timing, drive partitioning, precise thermal performance and BIOS configuration, 1975 front-panel binary programs.
- **Known pedagogical abstraction:** A real computer also needs an appropriate motherboard, power supply, buses, display path and often cooling; base infrastructure is prebuilt in early-era levels. More of those dependencies become interactive with each generation.
- **Future accuracy track:** peer review by a computer-history educator and current PC technician; attach part-level citations, capability constraints and measured evaluation scenarios before claiming full realism.
